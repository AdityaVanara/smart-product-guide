# Smart Product Comparison Guide

A Design Thinking project website on the "Online Shopping Product Selection Problem".

## What it includes
- Survey results from 57 online shoppers
- A comparison tool to compare up to 3 phones side by side
- A user feedback form saved in the browser (localStorage)

## Files
- index.html: page structure and content
- style.css: design
- script.js: comparison tool, survey bars and feedback

## How to run
Download the files and open index.html in a browser.
