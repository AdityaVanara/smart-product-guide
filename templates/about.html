About this project

Customers often find it hard to choose the right product on Amazon, Flipkart and Meesho. Different prices, specifications, reviews, ratings, seller reliability and discounts make decisions slow and stressful. The Smart Product Comparison Guide puts these facts side by side and explains its recommendations.

Data notice: products, prices, ratings and demo survey rows marked Sample are demo data. They are not verified live marketplace prices or real customer reviews. Replace them with your own checked data on the Products page.

How the five subjects are used

Design Thinking

The Home page walks through Empathize, Define, Ideate, Prototype and Test. The Feedback page collects real user input.

Python Programming

Flask handles every request in app.py. Functions and CRUD operations are in app.py, database.py and stats_analysis.py.

Web Technology

HTML templates in templates/, one CSS file, and JavaScript files that call the Flask API with fetch. The layout is responsive.

Artificial Intelligence

ai/recommendation.py ranks products using price, adjusted rating, specs, seller score and your priority, and gives reasons.

Probability & Statistics

Percentages, means, median, standard deviation, correlation and conditional probability, all calculated from database records.

Database (SQLite)

Tables: products, shortlist, survey_responses, survey_difficulties, feedback and preferences, linked with foreign keys.

Technology

Python 3 · Flask · SQLite · HTML · CSS · JavaScript. No chart library is used; the charts are drawn with plain JavaScript and SVG.

B.E. Computer Engineering, J.G. University, Ahmedabad.
